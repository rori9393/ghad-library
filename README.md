# مكتبة الغد | Ghad Library

موقع إلكتروني تجريبي لتنظيم زيارات الطلاب إلى مكتبة كلية الغد للعلوم الطبية التطبيقية – فرع جدة، وإدارة الكتب وعمليات الاستعارة والقراءة من خلال واجهة سهلة الاستخدام.

## فكرة المشروع

يهدف المشروع إلى تحويل تسجيل زيارات المكتبة من السجلات الورقية إلى نظام إلكتروني تجريبي، يتيح للطلاب تسجيل زياراتهم والاطلاع على الكتب المتاحة، ويساعد مسؤولة المكتبة على متابعة السجلات وإدارة عمليات الإرجاع.

## مميزات الموقع

### 1. تسجيل زيارات الطلاب
- تسجيل اسم الطالب ورقمه الأكاديمي.
- تحديد الغرض من الزيارة: قراءة، استعارة، أو شيء آخر.
- اختيار الكتاب المطلوب من الكتب المتاحة.
- إضافة التوقيع الإلكتروني.
- حفظ بيانات الزيارة في قاعدة البيانات.

### 2. معرض الكتب
- عرض الكتب الموجودة في المكتبة.
- البحث عن الكتب بالاسم.
- تصفية الكتب حسب التصنيف.
- عرض إجمالي النسخ والنسخ المتاحة والمستعارة وقيد القراءة.
- تحديث أعداد النسخ حسب عمليات الاستعارة والإرجاع.

### 3. لوحة مسؤولة المكتبة
- تسجيل الدخول باستخدام اسم المستخدم وكلمة المرور.
- عرض سجلات زيارات الطلاب.
- البحث عن السجلات.
- متابعة عمليات القراءة والاستعارة.
- تأكيد إرجاع الكتب.
- حذف السجلات حسب الصلاحيات.

## التقنيات المستخدمة

- **HTML5:** بناء صفحات الموقع.
- **CSS3:** تصميم وتنسيق الواجهات.
- **JavaScript:** برمجة الوظائف والتفاعلات.
- **Supabase:** قاعدة البيانات والمصادقة وإدارة الصلاحيات.
- **Supabase Edge Functions:** تنفيذ تسجيل الدخول باسم المستخدم.
